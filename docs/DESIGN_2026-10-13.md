# 화이트 톤 재디자인 · 2026-10-13

사용자 요청: 모바일에 최적화된 화이트 톤의 모던한 화면, 확정된 장소는 풍경·장소 사진 썸네일로 직관적으로, 글로 빽빡한 느낌 줄이기, Tailwind 사용, 확정 항목별 비용 기록.

여행 내용·예약·순서·지도 좌표·공유 상태 schema는 바꾸지 않았다. 모바일 구조(하단 탐색 5개, 지도/일정 분리, 고정 날짜, URL day/view 복원, 체크 상세·초점 보존)는 [MOBILE_UX_REVIEW.md](MOBILE_UX_REVIEW.md) 그대로 유지한다.

## 적용한 지침

- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md): 하나의 분명한 방향(밝은 바탕 + 사진이 주인공), 일관된 토큰, 장식보다 콘텐츠.
- [Vercel web-design-guidelines](https://github.com/vercel-labs/agent-skills/blob/main/skills/web-design-guidelines/SKILL.md): 안전 영역, 44px 터치, 의미 있는 HTML, 이미지 `alt`/지연 로딩.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): 카드형 목록, 요약 우선·상세 펼침, 하단 탐색 5개 이내.
- [WCAG 2.2 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): 일반 글자 4.5:1.

외부 스킬 실행 코드는 설치하지 않았다. Tailwind CSS 4.3.3(`tailwindcss`, `@tailwindcss/cli`)만 빌드용 devDependency로 고정 추가했다.

| `app.css` | Tailwind v4 원본. `@theme`, `@utility btn/btn-primary/card/icon-button`, `@layer components`. build.mjs가 CLI로 컴파일해 인라인 |

색: 바탕 white, 글자 slate-900/600/500, 포인트 teal-600/700. 상태 배지 emerald-50/700(확정), sky-50/700(방문 예정), amber-50/800(확인 필요), rose(마감). 글꼴은 Pretendard가 설치된 기기에서는 Pretendard, 아니면 Apple SD Gothic Neo·Malgun Gothic 등 기본 글꼴.

## 화면

- 상단: 브랜드 + D-day(한국 시간 11/3 기준, 여행 중/다녀왔어요 자동 전환). PC에서는 상단 탭.
- 날짜 히어로: 날짜별 대표 사진 + 제목·소개. 사진 아래 출처.
- 지도: 흰 카드 안에 실제 지도, 범위 선택, 선택 장소 카드(사진 썸네일), 사진 칩 형태의 시간 순서, 길찾기·검증 기록 펼침.
- 일정: 번호가 붙은 사진 썸네일 + 시간(호박색) + 제목 + 상태 + 두 줄 요약. 펼치면 메모·길찾기·편집·사진 출처.
- 예약·비용: 상단 합계 카드 → 여행 순서대로 8개 예약 카드(16:9 커버 사진, 날짜 칩, 핵심 정보 2칸, 비용 입력, 상세 펼침).
- PC(1000px 이상): 지도와 일정 2열.

### 사진 사용 원칙

예약한 객실·좌석 사진이 아니라 장소 분위기 사진이다. Vinpearl 리조트·Noska 호텔·YUJU SPA는 Commons에 해당 시설 사진이 없어 해변·선셋타운·즈엉동 사진을 쓰고 설명에 그대로 적었다("참고 사진" 표시). 지점이 확정되지 않은 나항센·분꽈이·KingKong Mart, 업체 미정인 남부 마사지는 다른 가게 사진을 쓰지 않고 아이콘 타일로 둔다.

## 비용 기록

- 예약 카드마다 금액 + 통화(KRW/VND/USD) 입력. 합계 카드에 원화 환산 총액, 항목별 금액, 환율 설정(기본 1 USD = 1,400원, 1,000 VND = 55원, 대략값이며 수정 가능).
- 저장: 이 기기 localStorage `phuquoc-costs-2026-v1`만. 공유 `planner_state`, 서버, 공개 소스에는 넣지 않는다. 기존 키·schema·worker 검증은 그대로다.
- 이유: 공개 사이트에 결제 금액을 올리지 않는 기존 원칙(테스트로 보호)과 Sites 재배포 없이 동작해야 하는 점. 두 기기 공유가 필요하면 별도 서버 schema 변경 + Sites 배포가 필요하다.
- 기본값: 이미 공개 요약에 있는 YUJU SPA 2인 1,500,000 VND만 표시. 사용자가 지우면 지운 상태를 유지한다.
- JSON 백업에 `costs`가 함께 저장되고, 가져올 때 같은 검증을 거친다.

## 검증 (Chrome 155, 로컬 빌드)

- `npm run build`, `npm test` 13개 통과(비용 검증·예약 순서·사진 출처/용량 테스트 3개 추가).
- 320px·390px 폭의 7개 화면에서 가로 넘침 0, 일반 글자 4.5:1 미만 0(사진 위 흰 글자는 그라데이션 위라 별도).
- 비용: 입력·서식·합계·USD 환산·환율 변경·잘못된 입력·새로고침 후 유지·공유 상태 키 미변경을 실제 브라우저로 확인.
- PC 1280px: 지도/일정 2열, 페이지 오류 없음.
- 확인하지 못한 것: 실제 iPhone Safari/Android 기기, 로그인 상태의 공유 저장 화면. 로그인 페이지 색 변경과 관리 화면 반영은 Sites 재배포 전까지 적용되지 않는다.
